Simple CRM Application
This is a straightforward Customer Relationship Management (CRM) application built with Flask and SQLite. It provides basic functionalities to help manage your customer interactions.

Features
Customer Management: You can easily create, view, and delete customer records.
Event Logging: For each customer, you can add chronological event logs to track interactions, notes, or any significant activities.
Persistent Data: All your customer and event data is securely stored in an SQLite database, so your information remains safe and accessible even after you close and restart the application.
